# 🐬 20-Day MySQL Challenge

Welcome to my **20-Day MySQL Challenge** 🚀

I am dedicating the next 20 days to learning and practicing **MySQL and SQL concepts** through hands-on exercises, queries, and real-world examples.

The goal of this challenge is to strengthen my **database fundamentals, SQL problem-solving skills, and MySQL knowledge**.

* ✅ Understand MySQL fundamentals

* ✅ Practice database and table operations

* ✅ Understand different types of JOINs
* ✅ Learn subqueries
* ✅ Practice constraints and relationships
* ✅ Understand indexes and views
