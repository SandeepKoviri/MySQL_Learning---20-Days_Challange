JOINS:
======
--> a JOin in MySQL is used to combine rows from two or more tables based on related columns.

example:
--------
emoloyee table --> employee records
department --> department details
-->if you want to see which employees belongings to which department you need to join these two tables.

why do we need joins:
---------------------
-->To fetch data from multiple tables in a single query
-->To reduce data duplication(instead of keeping everything in one table)
-->To implement relationships(one-to-one,one-to-many,many-to-one,many-to-many)
-->To generate report and analytics combing different datasets.

Types of JOins:
---------------
INNER JOIN --> MATCHED RECORDS FROM BOTH TABLES
LEFT JOIN --> MATCHED RECORDS + LEFT TABLE RECORDS 
RIGHT JOIN --> MATCHED RECORDS + RIGHT TABLE RECORDS
FULL JOIN --> INNER JOIN + LEFT JOIN + RIGHT JOIN
CROSS JOIN --> IT PERFOMS CARTESIAN PRODUCT

1.INNER JOIN:
-------------
--> Returns only the rows that have matched values in both values.
syntax:
--------
select columns from table1 inner join table2 on table1.common_column = table2.common_column;

2.LEFT JOIN:
------------
--> Returns all rows from the left table and the matched rows from the right table.if no match, null values appear for the right table columns
syntax:
------
select columns from table1 left join table2 on table1.common_column = table2.common_column;

3.RIGHT JOIN:
-------------
--> Returns all rows from the Right table and the matched rows from the left table.if no match, null values appear for the left table columns
syntax:
------
select columns from table1 right join table2 on table1.common_column = table2.common_column;

4.FULL JOIN:
------------
--> Returns union of left join and right join

syntax:
-------
select columns from table1 left join table2 on table1.common_column = table2.common_column;
union
select columns from table1 right join table2 on table1.common_column = table2.common_column;

5.CROSS JOIN:
-------------
--> Returns cartesian product --> every row from the first table with every row from the second table.

syntax:
------
select columns from table1 cross join table2;
