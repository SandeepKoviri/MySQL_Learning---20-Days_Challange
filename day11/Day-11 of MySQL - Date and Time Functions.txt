Date and Time function:
------------------------
curdate() --> return the current date
curtime() --> return the current time
now() --> returns both date and time
time() --> extract time part
date() --> extract date part
year() --> extract year
month() --> extract month
day() --> extract day of month
week() --> extract week number
dayofweek() --> day of week
date_add() --> add time to date
date_sub() --> add time of date
datediff() --> returns difference between dates
str_to_date() --> covert str to date
date_format() --> used to format date
last_day() --> returns last day of a month
makedate() --> make date using year and no of days
maketime() --> make time using hours,minutes and seconds
monthname() --> returns month name of a given date
dayname() --> returns day name of a given day
quarter() --> returns which quarter number based on month
sec_to_time() --> coverts sec to time
time_to_sec() --> coverts time to sec
sysdate() --> returns system date

Set Operators:
=============
UNION --> COMBINES RESULTS FROM TWO QUERIES AND REMOVES DUPLICATE ROWS AND COLUMNS MUST HAVE THE SAME NUMBER AND TYPE

UNION ALL --> COMBINES RESULTS FROM TWO QUERIES AND INCLUDES ALL ROWS,INCLUDING DUPLICATES. COLUMNS MUST HAVE THE SAME NUMBER AND TYPE

INTERSECT --> RETURNS ROWS THAT ARE COMMON TO BOTH QUERIES.COLUMNS MUST HAVE THE SAME NUMBER AND TYPE 
	     
MINUS --> RETURNS ROWS FROM THE FIRST QUERY THAT ARE NOT PRESENT IN THE SECOND QUERY.COLUMNS MUST HAVE THE SAME NUMBER AND TYPE
	  NOTE:MYSQL DOESN'T SUPPORT MINUS DIRECTLY

EXCEPT --> RETURNS ROWS FROM THE FIRST QUERY THAT ARE NOT PRESENT IN THE SECOND QUERY.COLUMNS MUST HAVE THE SAME NUMBER AND TYPE
